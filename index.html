Centro de Asistencia & Solución de Errores

Todo lo que necesitas saber si surge un código de emparejamiento, bloqueo o cambio de número.

¿Por qué me sale "Access not configured / Pairing Code"?

OpenClaw incluye un escudo de seguridad por defecto para que extraños no consuman tus tokens de IA. Cuando un número no autorizado escribe por primera vez, el sistema solicita aprobación.

Solución de 1 clic: En la app, ve a "Canales -> WhatsApp" y cambia la política a Acceso Abierto (Público) para responder a todos los clientes, o aprueba el número específico.

¿Me conviene usar WhatsApp Normal o WhatsApp Business?

Recomendamos 100% WhatsApp Business porque te permite configurar tu catálogo, respuestas rápidas de respaldo, etiquetas para clasificar clientes y soporta mejor un flujo constante de mensajería empresarial.

¿Cómo se administran los tokens y la API Key de Gemini?

Tu clave se almacena cifrada a nivel de entorno (env.GEMINI_API_KEY). El asistente utiliza el modelo gemini-3.5-flash-lite que ofrece la velocidad más alta del mercado con un costo mínimo por millón de tokens.

¿Qué hacer si aparece "Auth store lock may be busy"?

Ocurre cuando el servicio del Gateway está utilizando activamente la base de datos en segundo plano. Nuestro instalador visual ahora inyecta las variables directamente al entorno para evitar cualquier bloqueo de SQLite.
